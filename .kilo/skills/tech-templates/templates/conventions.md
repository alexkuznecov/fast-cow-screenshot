## 5. Стиль кода

- Форматирование: <ktlint / IntelliJ Kotlin style>, отступ 4 пробела, максимальная длина строки <N>.
- Именование: классы `PascalCase`, функции и свойства `camelCase`, константы `UPPER_SNAKE_CASE` в `companion object` или top-level `const val`.
- Один публичный класс/интерфейс — один файл, имя файла = имя класса.
- Видимость: по умолчанию `internal`; `public` — только для явно описанных в задаче контрактов.
- Null-safety: оператор `!!` запрещён; платформенные типы из Java/JNA сразу приводятся к явному Kotlin-типу.
- Неизменяемость: `val` и неизменяемые коллекции по умолчанию; `data class` для значений.
- Ошибки: <например: ожидаемые ошибки — `sealed interface …Result`; исключения — только для программных ошибок>.
- Комментарии и KDoc: <язык, когда обязательны>.
