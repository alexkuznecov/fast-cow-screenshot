# US-002: Захват всех мониторов одним изображением

| Поле | Значение |
|---|---|
| Статус | Review |
| Приоритет | Must |
| Оценка | M |
| Требования | REQ-001.1, REQ-001.2, REQ-001.9–REQ-001.12, REQ-001.20, REQ-001.52, REQ-001.N2, REQ-001.N6, REQ-001.N11 |

## История

**Как** пользователь с несколькими мониторами,
**я хочу** одной горячей клавишей снять все мониторы в одно изображение,
**чтобы** зафиксировать всё рабочее пространство целиком (например, для отчёта об ошибке или инструкции).

## Критерии приёмки

### AC-1: Склейка с сохранением раскладки
- **Given** монитор A 1920×1080 (основной) и монитор B 2560×1440, расположенный слева от A, верхние края выровнены
- **When** пользователь нажимает `Ctrl+Shift+2` (горячая клавиша «Все мониторы» по умолчанию)
- **Then** создаётся одно изображение 4480×1440: B слева, A справа, взаимное расположение как в параметрах дисплея Windows

### AC-2: Заливка пустых зон
- **Given** конфигурация из AC-1 (у A высота меньше, чем у B)
- **When** выполняется захват всех мониторов
- **Then** область под монитором A (1920×360) залита непрозрачным серым цветом `#808080`

### AC-3: Смешанный масштаб
- **Given** ноутбук 2880×1800 с масштабом 200 % и внешний монитор 1920×1080 с масштабом 100 %
- **When** выполняется захват всех мониторов
- **Then** каждый монитор на изображении представлен в физическом разрешении, на стыке нет разрывов, наложений и масштабирования

### AC-4: Изменение конфигурации во время работы
- **Given** приложение запущено с двумя мониторами
- **When** пользователь отключает один монитор и делает захват всех мониторов
- **Then** изображение содержит только оставшийся монитор, перезапуск приложения не нужен

### AC-5: Производительность
- **Given** эталонная конфигурация с тремя мониторами 3840×2160
- **When** выполняется захват всех мониторов (50 замеров)
- **Then** p95 времени от нажатия клавиши до появления изображения в буфере обмена ≤ 700 мс

## Граничные случаи

- Мониторы в режиме дублирования — область включается один раз (REQ-001.12).
- Монитор в портретной ориентации и со смещением по вертикали.
- Очень большой виртуальный рабочий стол (11520×2160 и больше) — контроль памяти (REQ-001.N6).
- Один монитор — результат совпадает с US-001.
- Включена настройка указателя мыши — указатель рисуется в своей позиции на общем изображении (REQ-001.53).

## Заметки / UI

- Цвет заливки пустых зон — серый `#808080`, не настраивается (REQ-001.11).
