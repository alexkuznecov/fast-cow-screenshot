# US-006: «Сохранить как…» в выбранную директорию

| Поле | Значение |
|---|---|
| Статус | Review |
| Приоритет | Must |
| Оценка | S |
| Требования | REQ-001.31, REQ-001.36–REQ-001.42, REQ-001.55, REQ-001.57 |

## История

**Как** пользователь,
**я хочу** сохранить последний снимок в произвольную папку под своим именем,
**чтобы** сразу положить его в папку проекта или задачи, не перенося файл вручную.

## Критерии приёмки

### AC-1: Первое открытие диалога
- **Given** в текущем сеансе сделан хотя бы один снимок, «Сохранить как…» ещё ни разу не использовалось
- **When** пользователь выбирает «Сохранить как…» в уведомлении о захвате или в меню трея
- **Then** открывается стандартный диалог сохранения Windows: начальная папка — директория по умолчанию, имя предзаполнено по шаблону `Screenshot_yyyy-MM-dd_HH-mm-ss.png`, фильтр `PNG (*.png)`

### AC-2: Сохранение копии
- **Given** диалог «Сохранить как» открыт
- **When** пользователь выбирает папку `D:\Projects\Bug-42`, вводит имя `login-error` и нажимает «Сохранить»
- **Then** создаётся файл `D:\Projects\Bug-42\login-error.png`; автосохранённый файл в директории по умолчанию остаётся на месте; директория по умолчанию не меняется

### AC-3: Повторное открытие — последняя выбранная папка
- **Given** пользователь ранее сохранил снимок через «Сохранить как…» в `D:\Projects\Bug-42`
- **When** пользователь делает новый снимок и снова выбирает «Сохранить как…»
- **Then** диалог открывается в папке `D:\Projects\Bug-42`

### AC-4: Последняя папка запоминается между запусками
- **Given** последняя папка «Сохранить как» — `D:\Projects\Bug-42`
- **When** пользователь перезапускает приложение, делает снимок и выбирает «Сохранить как…»
- **Then** диалог открывается в папке `D:\Projects\Bug-42`

### AC-5: Последняя папка недоступна
- **Given** последняя папка «Сохранить как» удалена или находится на отключённом диске
- **When** пользователь выбирает «Сохранить как…»
- **Then** диалог открывается в директории по умолчанию

### AC-6: Только PNG
- **Given** диалог «Сохранить как» открыт
- **When** пользователь вводит имя `login.jpg` и нажимает «Сохранить»
- **Then** создаётся файл `login.jpg.png` в формате PNG

### AC-7: Перезапись существующего файла
- **Given** в выбранной папке уже есть файл с указанным именем
- **When** пользователь нажимает «Сохранить»
- **Then** показывается запрос подтверждения перезаписи; при отказе файл не меняется

### AC-8: Снимка нет
- **Given** приложение только что запущено, снимков не было
- **When** пользователь открывает меню трея
- **Then** пункт «Сохранить как…» недоступен

### AC-9: Сохраняется последний снимок
- **Given** пользователь сделал снимок 1, затем снимок 2
- **When** пользователь выбирает «Сохранить как…»
- **Then** сохраняется снимок 2

### AC-10: Отмена диалога
- **Given** диалог «Сохранить как» открыт
- **When** пользователь нажимает «Отмена»
- **Then** файлы не создаются, последняя папка «Сохранить как» не меняется, последний снимок остаётся доступен для повторного «Сохранить как…»

## Граничные случаи

- Имя без расширения — дописывается `.png`; имя с другим расширением или с точкой (`v1.2`) — тоже дописывается `.png` (REQ-001.39).
- Расширение `.PNG` в верхнем регистре — повторно не дописывается.
- Папка без прав записи — диалог Windows или приложение показывает ошибку, снимок не теряется.
- Новый захват, пока открыт диалог, — **Допущение:** диалог сохраняет снимок, который был последним в момент открытия диалога.
- Уведомление скрылось через 3 с — «Сохранить как…» доступно из меню трея.

## Заметки / UI

- Горячей клавиши для «Сохранить как…» нет (REQ-001.57, Won't).
- Последняя папка «Сохранить как» хранится в настройках отдельно от директории по умолчанию (REQ-001.55).
