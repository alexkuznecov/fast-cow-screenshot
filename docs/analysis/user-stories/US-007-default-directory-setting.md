# US-007: Настройка директории по умолчанию

| Поле | Значение |
|---|---|
| Статус | Review |
| Приоритет | Must |
| Оценка | S |
| Требования | REQ-001.43–REQ-001.51 |

## История

**Как** пользователь,
**я хочу** указать папку, куда автоматически сохраняются снимки,
**чтобы** все снимки попадали в удобное мне место (например, на диск D: или в синхронизируемую папку).

## Критерии приёмки

### AC-1: Значение при первом запуске
- **Given** приложение запускается впервые
- **When** пользователь открывает настройки
- **Then** директория по умолчанию — системная папка «Снимки экрана» (`FOLDERID_Screenshots`, та же, что использует Win+PrtSc), с учётом перенаправления в OneDrive

### AC-2: Выбор новой директории
- **Given** окно настроек открыто
- **When** пользователь нажимает «Обзор…», выбирает папку `D:\Скриншоты` и подтверждает
- **Then** в настройках отображается `D:\Скриншоты`, следующий снимок автосохраняется в эту папку

### AC-3: Сохранение между запусками
- **Given** пользователь установил директорию `D:\Скриншоты`
- **When** приложение перезапускается
- **Then** директория по умолчанию — `D:\Скриншоты`

### AC-4: Недоступная для записи директория
- **Given** окно настроек открыто
- **When** пользователь выбирает папку без прав записи (например, `C:\Windows\System32`)
- **Then** показывается сообщение об ошибке, прежнее значение остаётся

### AC-5: Временно недоступная директория
- **Given** директория по умолчанию на сетевом диске, который сейчас отключён
- **When** приложение запускается
- **Then** настройка не сбрасывается; при захвате ошибка обрабатывается по US-005 AC-4

### AC-6: Сброс к значению по умолчанию (Could)
- **Given** директория по умолчанию изменена пользователем
- **When** пользователь нажимает «Сбросить»
- **Then** директория возвращается к значению из AC-1

## Граничные случаи

- Путь с кириллицей и пробелами (Must), UNC-путь (Should), путь длиннее 260 символов (Could).
- Пользователь выбирает корень диска (`D:\`).
- Файл настроек повреждён или удалён — применяется значение из AC-1.
- Папка `FOLDERID_Screenshots` не существует и не определена — используется `%USERPROFILE%\Pictures`.

## Заметки / UI

- Окно настроек: поле только для чтения с путём, кнопки «Обзор…», «Открыть папку», «Сбросить».
- Смена директории по умолчанию не влияет на последнюю папку «Сохранить как» (REQ-001.55).
- Механизм хранения настроек — кандидат в ADR (см. RES-001).
